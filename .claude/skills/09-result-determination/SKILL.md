# 确定估价结果

## 触发条件
所有选用的估价方法测算完成后。

## 执行步骤
1. 对各方法的测算结果进行校核（6.0.2~6.0.3条）
2. 比较不同方法的测算结果差异
3. 选用简单/加权算术平均得出综合测算结果（6.0.5条）
4. 考虑未反映的价值影响因素，确定最终评估价值（6.0.6条）

## 规范约束
- 6.0.2条：应对各方法测算结果进行校核
- 6.0.3条：检查11项内容
- 6.0.5条：多方法结果的综合
- 6.0.6条：最终评估价值的确定

## 输入
- 各方法的 CalculationResults

## 输出
- FinalEstimationResult: 综合结果、最终评估价值

## 注意事项
- 最终评估价值的精度应满足估价目的需要（6.0.6条第3款）
