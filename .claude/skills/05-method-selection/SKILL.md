# 选用估价方法

## 触发条件
实地查勘完成、资料齐全后，选择适用的估价方法。

## 执行步骤
1. 调用 assessMethodApplicability 判断适用的估价方法
2. 向用户展示推荐的方法列表
3. 接受用户的手动覆盖（增加/删除方法）
4. 记录最终选用的方法

## 规范约束
- 4.1.2条：
  - 同类房地产有较多交易的，应选用比较法
  - 有租金等经济收入的，应选用收益法
  - 没有交易且没有收益的，应选用成本法
  - 具有开发或再开发潜力的，应选用假设开发法
- 4.1.3条：适用两种以上方法时，宜同时选用所有适用的方法，不得随意取舍

## 输入
- CollectedData（用于判断方法适用性）

## 输出
- EstimatedMethod[]: 选用的估价方法列表

## 注意事项
- 如果只有 1 个方法适用，应 warning 但不停止流程
