# 编制估价作业方案

## 触发条件
需求澄清完成后，需要编制估价作业方案。

## 执行步骤
1. 分析估价项目的规模、难度和完成时间（3.0.4条）
2. 确定拟采用的估价方法和估价技术路线（3.0.4条第1款）
3. 拟定搜集估价所需资料及其来源渠道（3.0.4条第1款）
4. 制定具体步骤及时间进度（3.0.4条第2款）
5. 确定人员安排（3.0.4条第3款）

## 规范约束
- 3.0.4条：估价作业方案应包括估价工作的主要内容及质量要求、具体步骤及时间进度、人员安排
- 3.0.2条第3款：应至少选派两名注册房地产估价师共同进行估价

## 输入
- EstimationDemand, EstimationObject

## 输出
- EstimationPlan: 技术路线、方法选择策略、资料清单、时间安排

## 注意事项
- 方案应针对估价项目编制，不应套用通用模板
