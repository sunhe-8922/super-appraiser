# 撰写估价报告

## 触发条件
估价结果确定后，撰写正式报告。

## 执行步骤
1. 选择报告风格（叙述式/表格式）
2. 加载对应模板
3. 填充数据生成报告
4. 输出指定格式（Markdown/HTML/PDF/Word）

## 规范约束
- 7.0.1条：报告应采取书面形式，真实、客观、准确、完整、清晰、规范
- 7.0.2条：叙述式报告包括8个部分
- 7.0.3条：抵押估价报告需包含变现能力分析
- 7.0.16条第6款：报告使用期限不宜超过一年
- 7.0.17条：表格式报告适用于成套住宅抵押估价和批量估价

## 输入
- FinalEstimationResult, EstimationContext

## 输出
- EstimationReport: 完整估价报告

## 注意事项
- 报告应图文并茂（7.0.22条）
- 抵押估价需含变现能力分析（7.0.20条）
