# 审核估价报告

## 触发条件
报告撰写完成后，交付前审核。

## 执行步骤
1. 对照规范审查报告内容和格式
2. 检查 7.0.2 规定的各部分是否齐全
3. 检查数据一致性和计算准确性
4. 形成审核记录

## 规范约束
- 3.0.11条：交付前应审查核定内容和形式，形成审核记录
- 3.0.12条：审核合格后由不少于两名注册房地产估价师签名
- 7.0.1条：报告应真实、客观、准确、完整、清晰、规范

## 输入
- EstimationReport

## 输出
- 审核记录（含审核意见、结论、日期、人员签名）

## 注意事项
- 审核记录应记载审核的意见、结论、日期和人员及其签名（3.0.11条）
