# 成本法估价测算

## 触发条件
方法选择阶段确定了成本法。

## 执行步骤
1. 选择估价路径（优先房地合估，4.4.2条）
2. 测算土地重置成本（4.4.4条）
3. 测算建筑物重置成本（4.4.5条）
4. 测算建筑物折旧（4.4.7~4.4.13条）
5. 计算成本价值（4.4.15条）

## 规范约束
- 4.4.2条：优先选择房地合估路径
- 4.4.3条：重置成本 = 土地成本+建设成本+管理费用+销售费用+投资利息+销售税费+开发利润
- 4.4.7条：折旧 = 物质折旧+功能折旧+外部折旧
- 4.4.9条：折旧测算方法（年龄-寿命法/市场提取法/分解法）

## 输入
- CollectedData.costData, CollectedData.benchmarkLand

## 输出
- CostResult: 重置成本、折旧、成本价值

## 注意事项
- 在建工程和新近开发完成的房地产可不扣除折旧（4.4.16条）
