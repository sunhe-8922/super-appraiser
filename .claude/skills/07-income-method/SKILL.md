# 收益法估价测算

## 触发条件
方法选择阶段确定了收益法。

## 执行步骤
1. 选择估价方法（优先报酬资本化法，4.3.2条）
2. 测算收益期（4.3.6条：取土地剩余期限和建筑经济寿命孰短）
3. 测算未来收益（4.3.8条：有效毛收入-运营费用）
4. 确定报酬率/资本化率（4.3.14条）
5. 计算收益价值

## 规范约束
- 4.3.2条：优先选用报酬资本化法
- 4.3.6条：收益期取土地使用权剩余期限和建筑物剩余经济寿命孰短
- 4.3.8条：净收益=有效毛收入-运营费用
- 4.3.14条：报酬率确定方法（市场提取法/累加法/排序插入法）

## 输入
- CollectedData.rentalData, CollectedData.marketIndex

## 输出
- IncomeResult: 净收益、资本化率、收益价值

## 注意事项
- 有租约限制的，应按合同租金或市场租金分别处理（4.3.10条）
