# 搜集估价所需资料

## 触发条件
估价方案确定后，开始搜集资料。

## 执行步骤
1. 按方案中的资料清单搜集数据
2. 通过 Kimi WebBridge 获取市场数据（默认数据源）
3. 检查资料的真实性、准确性和完整性（3.0.6条）
4. 记录资料来源

## 规范约束
- 3.0.5条：应搜集四类资料：
  - 反映估价对象区位、实物和权益状况的资料
  - 估价对象及其同类房地产的交易、收益、成本等资料
  - 对估价对象所在地区的房地产价值和价格有影响的资料
  - 对房地产价值和价格有普遍影响的资料
- 3.0.6条：应检查资料，查看权属证明原件，复印件与原件核对

## 输入
- EstimationPlan 中的资料清单

## 输出
- CollectedData: 可比实例、租金数据、市场指数、成本数据

## 注意事项
- 优先使用 Kimi WebBridge 获取实时数据
- 数据缺失时应记录并告知用户
